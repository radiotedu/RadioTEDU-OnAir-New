# RadioTEDU Play History — Snapshot (2026-08-29)

This folder is a **sanitized, static snapshot** of the continuous play-history exports generated by the song reporting system.

## Contents
- \RadioTEDU-play-history-daily.csv\ — today's all-radio events (human-readable, station_name + mounts)
- \RadioTEDU-play-counts-daily.csv\ / \-total.csv\ — aggregated play counts
- \RadioTEDU-play-history-total.csv\ — all-time events (21 MB)
- \RadioTEDU-play-history-manifest.json\ — integrity manifest with hash-chain verification
- \daily/\ — last 10 daily event/count CSVs
- \licensor/\ + \licensor/MESAM/\ — rights reports and MESAM radio forms per station

## Why no .db file here?
The live \cleanroom.db\ (~106 MB) contains Icecast credentials, JWT secrets, and user password hashes and is **explicitly excluded** by \.gitignore:11\ and \SECURITY.md\. Only the **derived, public-safe CSV/JSON reports** are included here.
