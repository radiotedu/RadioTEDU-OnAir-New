# RadioTEDU Weekly Daypart Programs

Timezone: **Europe/Istanbul**. A 22:00–02:00 program belongs to the day on which it starts and keeps its name after midnight. Monday preserves the original program names. BPM bands remain consistent by time slot throughout the week, while every program name is unique within its station.

## Broadcast-safety policy

1. Select least-played music inside the active weekday program's BPM range.
2. If the range has no available analyzed music, use eligible tracks with unknown BPM while analysis catches up.
3. If neither group is available, use any eligible music. A BPM rule is never allowed to create dead air.
4. Jingles, manual queue items, scheduled items, advertisements, emergency audio, and live sources keep their existing priority and are not filtered by daypart BPM.

The tempo direction is informed by published evidence associating faster tempo with greater perceived arousal; the specific names, hours, and genre ranges are RadioTEDU editorial choices. See [Yang et al., 2025](https://pmc.ncbi.nlm.nih.gov/articles/PMC11893886/) and [Liu et al., 2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC6243583/).
