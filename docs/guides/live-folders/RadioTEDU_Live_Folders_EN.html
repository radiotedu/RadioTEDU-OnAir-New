How to add music and let OnAir queue it automatically

This guide is for non-technical staff. Put a completed audio file into the correct station folder; RadioTEDU OnAir watches the folder, validates the file, imports its metadata and makes it eligible for the next safe queue refill.

Verified on this PC: A test file copied into the live Energize folder was imported in about 10–15 seconds and was automatically deactivated when removed. No station was restarted.

1. Choose the correct folder

StationLive folderApplication / mountContent rule
ClassicalH:\RadioTEDU Songs\Classical/classic, /classic-low, /classic-flacGenuine classical works. Do not add “No Copyright”, “Royalty Free” or stock/video music.
Lo-FiH:\RadioTEDU Songs\lofi/lofi, /lofi-lowLo-Fi and licensed independent material. No-copyright material is allowed only here.
Pop / RadioTEDUH:\RadioTEDU Songs\Pop/radio, /radio-lowLicensed/owned pop. Do not add no-copyright, stock or background-music packs.
Jazz / CazzH:\RadioTEDU Songs\Jazz/cazz, /cazz-low, /cazz-flacJazz only. FLAC is enabled only for this station.
RockH:\RadioTEDU Songs\Rock/rock, /rock-lowRock only. Do not add video-title, stock or no-copyright packs.
EnergizeH:\RadioTEDU Songs\Energize/energize, /energize-lowActually energetic: dance, electronic, pop-dance, house, energetic rock, etc. The safe active library currently has 84 tracks; do not use the legacy no-copyright folder.
Important: H:\Broadcast\RadioTEDU-OnAir\Playlists\energize\audio is a legacy folder. Its indexed material is largely labelled “Copyright Free/No Copyright Music”, so it was not moved into the live Energize folder.

2. Prepare the file

Step A — Finish the copy

Download or copy the file completely before placing it in a live folder. A half-written file can fail validation.

Step B — Add tags

Set Artist, Title, Album and, when known, Genre. MusicBrainz Picard is suitable for exact metadata matches. Do not add Turkish-language tracks for now.

Step C — Use an audio format

MP3, FLAC, M4A, AAC/ADTS, WAV, OGG/Opus and other supported audio extensions are accepted. Do not copy ZIP/RAR archives.

3. Put it in the live folder

  1. Open Windows File Explorer.
  2. Open the station folder from the table.
  3. Copy the prepared audio file into it. Subfolders are watched too.
  4. Wait until the copy is complete and the file size stops changing.
  5. Normally no button is required. The watcher needs two identical observations; in practice the file is imported in about 10–15 seconds.
  6. The current song is not cut. The new file becomes eligible for a safe future queue position.
Pipeline: folder scan → playable/metadata validation → station library import → automatic queue refill. A PC or broadcast restart is not required.

4. Verify it

  1. Select the station in OnAir and open Media.
  2. Confirm that Managed music folder shows the expected path.
  3. If you do not want to wait, click Rescan managed folder now.
  4. The watcher should show “verified / watching” with zero retry errors.
  5. The file may not appear in the queue immediately. If the queue is already full, it is selected when space opens; this protects the live programme from an abrupt cut.

5. Metadata and MusicBrainz rule

  • Embedded file tags are authoritative; the filename is only a fallback clue.
  • If Artist/Title is uncertain, do not guess. Use an exact MusicBrainz title + artist match before putting the file on air.
  • On this PC, 28 exact matches were corrected and written into the audio files; original files are kept in the recovery backup.
  • Forty “No Copyright/Royalty Free/Free Music” Classical tracks were excluded from autoplay on non-Lo-Fi stations. Files were not deleted.
  • After tagging, do not rename the file; the watcher follows its path.

6. PC startup and internet recovery

  • RadioTEDU.OnAir.Supervisor is an Automatic Windows service and depends on Tcpip + Dnscache.
  • If the service crashes, Windows retries it after 5, 15 and 30 seconds.
  • Icecast output retries with 1, 2, 4, 8, 15 and 30-second backoff. When internet connectivity returns, the mount reconnects.
  • All six active stations have broadcast_autostart_enabled=true; AI, voting and Juke are disabled.
  • If the origin is temporarily unreachable, local programme generation continues and the encoder reconnects when the network is back.

7. Troubleshooting

SymptomAction
File does not appearCheck the station folder, extension and completed copy; then click Rescan.
Metadata is blankTag the file with MusicBrainz Picard; save it and wait for the watcher to rescan.
It does not play immediatelyThat is expected: the current song is never cut. The file is selected when the queue needs another item.
Mount disconnectsDo not reboot immediately. Allow the 1–30-second Icecast retry loop to reconnect and check OnAir health.
Validation keeps failingMove the file out of the live folder into a quarantine folder and report the station, filename and time.
